Implemented Commands

  • /statusDashboard health, pending todos, focus, weather, and water.
  • /todosList pending todos.
  • /todo add <title>Add a deterministic todo.
  • /todo done <id>Mark a todo done.
  • /notesList recent notes.
  • /note add <title> | <body>Add a note.
  • /weatherShow cached/auto-refreshed weather facts.
  • /focus status|start|pause|resume|complete|stopControl focus sessions.
  • /waterShow hydration status.
  • /water add <ml>Add water intake.

{{ icon_check(16) }} Setup Checklist

  1. Create the bot with @BotFather and copy the token.
  2. Send a private /start message to the bot, or add it to the exact group/channel you want to allow.
  3. Call getUpdates once to read the numeric chat.id.
  4. Set JIRI_TELEGRAM_BOT_TOKEN and JIRI_TELEGRAM_ALLOWED_CHAT_IDS on the Pi.
  5. Start the JIRI Telegram polling worker with scripts/run_telegram.sh.

{{ icon_database(16) }} Current Scope

This page is a binding/status surface. It intentionally does not save tokens through the browser and does not execute Telegram commands from the web UI.

  • AllowedPolling, explicit allowlist, deterministic JIRI commands.
  • BlockedShell execution, systemd control, AI-owned state changes, implicit geocoding.
  • NextTelegram poller implementation will use getUpdates and sendMessage.
