How JIRI uses AI

Every {{ activity.refill_interval_minutes }} minutes the background worker picks the emptiest buckets (a category + mood the screen asked for), sends one chat request per bucket to the first healthy provider, and keeps only the lines that pass the sanitizer (length, slots, no invented numbers). The display then picks a cached line locally; a bucket with no lines uses JIRI's built-in wording. AI never sees or changes todos, timers, weather, or settings.
